本周给了 W38 核心论断一组干净的对照实验——同样是 Steal An Egg 的衍生，复制"皮肤"的速死、复制"内核"并结构改造的存活：

游戏简介

一款把 Steal An Egg 的偷蛋玩法原样照搬、仅加一层"挖蛋"动作的皮肤换皮衍生品——开发者直接取名 "ILGames x Eggs"，官方简介末尾白纸黑字写着 "Game inspired by steal an egg"。两份官方文案并排，同构关系一目了然：

Steal An Egg · 本周 #1 · 官方文案

从宠物身边偷蛋 → 孵蛋收集稀有宠物 → 宠物产出金钱 → 升级跑步机与基地 → 训练提升速度 → 从其他玩家手里偷蛋 → 发现更稀有的蛋 / 宠物 / 变异

Break and Steal an Egg · 本作 · 官方文案

敲碎蛋孵出稀有动物 → 偷走它们并躲避守卫 → 放进基地赚现金 → 升级你的速度与镐子 → 在图鉴里集齐全部！（并自认"灵感来自 steal an egg"）

同一套"蛋 → 宠 / 动物 → 产钱 → 升级速度 → 更稀有"的增量复利骨架，本作唯一的"新意"是把"偷"前面加了个"敲碎（挖蛋）"动作——没有像 Ride A Pet 那样做任何结构改造：

1保留偷窃 PvP + 守卫——与龙头同样的对抗 / 被偷结构，没有做人群扩面。
2没有独立长轴——速度 + 镐子双升级照抄龙头，无"速度做唯一长轴"之类的简化改造。
3零变现、零留存钩子——0 档通行证虽降低付费摩擦，但也意味着没有养成深度与长线目标设计。

RussoPlays 持续锚定增量 / 偷蛋 / ＋1 生态，是本周唯一与发现池元玩法同频的频道推断 — 他整周覆盖 Steal An Egg 更新、+1 Loot To Forge（#20）、+1 Stone Skipping Simulator、多款 Clicker / Incremental。这印证增量 / 偷蛋是当前 churn 最密集的赛道，但他覆盖的全是"已上榜头部 + 更新"，而非本周新衍生——与"新衍生纯算法脉冲、速生速死"的格局一致。

SharkBlox / Flamingo 的万圣节与怀旧选题 = 季节信号推断 — SharkBlox 全周产能押在 "Roblox Halloween 2026" 平台活动，Flamingo 转向怀旧恐怖，与数据侧 Dandy's World（🎃 +254%）/ DOORS（+65%）的万圣节脉冲互为佐证。W41-W43 值得观察万圣节脉冲的峰值时点与主播跟进节奏（恐怖 / 吉祥物生存类是否会被更多主播集中覆盖）。

Steal An Egg · 龙头首次降温后能否企稳，衍生赛道是否整体退潮

本周连续第 7 周守 #1，但量级登顶来首次明显回落（397.3万→340.0万，-14.4%）。W41 关键看：①龙头能否在 300 万级企稳，还是开启持续下行（若持续回落，说明偷蛋元玩法整体进入衰退期）；②本周扎堆的偷蛋衍生新品（Break and Steal an Egg 等）是否如期集体退场；③是否还有新衍生继续涌入。它是判断"偷蛋元玩法生命周期拐点"的核心标杆。最高优先级。

03

Dandy's World / DOORS · 万圣节脉冲半衰期与峰值时点

Dandy's World（🎃 更新 +254% 冲 #12）、DOORS（恐怖季 +65% 冲 #15）本周由万圣节季节内容驱动。W41-W43 观察：①脉冲峰值是否出现在万圣节正日（10.31）前后；②季节结束后的回落节奏（对照 W32 Dandy's World 0.25.1 更新脉冲在 2-3 周内回落至基线）。完善"季节内容驱动老盘的脉冲半衰期"经验值。中高优先级。

04

Build the Pyramid · 增量 + 协作结构改造能否转稳态

本周 #52（2.78万，95.07% 好评、100 人大服、周内低波动），是本周唯一非偷蛋真新品，走"增量 + 协作共建"的改造路径。W41 看它能否靠协作 + 大服的留存优势把 2.78万 继续抬升（验证"协作改造"是否与"去 PvP 改造"同样有效），以及 10 档中变现是否随量级加重。中优先级。

05

偷蛋换皮退场速度 / Karinderya 本地化失守后能否反弹

偷蛋换皮：Break and Steal an Egg 周日已跌至 1.77万，W41 看它与 4 款衍生合卡标的（Steal From The Rich / +1 Wings / +1 Strength / Steal A Verity）的退场速度，佐证"皮肤换皮一次脉冲即死"。Karinderya：本周 #28→#65（-60%），本地化明星盘首次崩塌，W41 看它是触及区域天花板后的永久回落，还是可靠新内容反弹（校准"本地化护城河量级上限"判断）。中优先级。
